# Sound Resources

Ця папка містить звукові ресурси для MindPlay.

## Необхідні файли

Додайте наступні аудіо файли (формат .mp3, .ogg, або .wav):

### Короткі звуки (SoundPool)
- `tap.mp3` - звук натискання на кнопку (короткий click)
- `correct.mp3` - звук правильної відповіді (позитивний тон)
- `wrong.mp3` - звук неправильної відповіді (негативний тон)

### Тони Simon (MediaPlayer)
- `simon_green.mp3` - тон для зеленої кнопки Simon
- `simon_orange.mp3` - тон для оранжевої кнопки Simon
- `simon_pink.mp3` - тон для рожевої кнопки Simon
- `simon_yellow.mp3` - тон для жовтої кнопки Simon

## Рекомендовані параметри

- **Тривалість**: 100-500мс для tap/correct/wrong, 500-1000мс для simon тонів
- **Формат**: MP3 або OGG (OGG рекомендується для менших розмірів)
- **Якість**: 128kbps достатньо для коротких звуків
- **Sample rate**: 44100 Hz

## Де знайти звуки

Безкоштовні ресурси:
- https://freesound.org/
- https://mixkit.co/free-sound-effects/
- https://pixabay.com/sound-effects/

## Тимчасове рішення

Якщо звукові файли ще не додані, SoundManager автоматично обробить їх відсутність
без крашу додатку.
